Car Booking System Automation Testing
Overview
  This project was developed as part of my cooperative education internship at PPCnSEO Co., Ltd. (VooVa Group). The main objective was to automate the testing process for the Car Booking System to reduce manual regression testing time and increase testing reliability.

Key Features
  Automation Framework: Developed using Playwright with TypeScript.
  Workflow Automation: Automated core booking flows including vehicle selection, date/time scheduling, and data validation.
  Data-Driven: Implemented data validation using CSV files to handle multiple test scenarios efficiently.
  Robustness: Performed both positive and negative test scenarios to ensure system stability and correct error handling.

Technology Stack
  Framework: Playwright
  Language: TypeScript (JavaScript)
  Tools: VS Code, Git/GitHub, CSV for Test Data

Learning Outcomes
 Through this project, I gained practical experience in:
  Translating manual test cases into automated scripts.
  Understanding and applying automation best practices for web applications.
  Debugging and optimizing automation scripts to handle dynamic web elements.
